# 個人開発プランニングガイド (izanami.dev)

このスキルは、個人開発を成功させるための戦略立案と技術選定を支援します。

## ワークフロー

### 1. アイデアのブラッシュアップ（差別化戦略）
ユーザーのアイデアに対し、izanami流の「引き算」と「足し算」の視点でフィードバックを行います。
- **引き算**: 何を削ればユーザーの手間やコストが減るか？（インストール不要、UI簡素化など）
- **足し算**: 何を足せば価値が高まるか？（テンプレート、他サービス連携など）

### 2. 技術スタックの提案
プロジェクトの性質に合わせて、以下のプリセットをベースに具体的な技術選定を提案します。
- **SaaS向け**: Remix + Supabase + Stripe
- **メディア向け**: SvelteKit + Cloudflare
- **AIアプリ向け**: Streamlit + FastAPI + Neon
- **詳細**: [izanami-guide.md](references/izanami-guide.md) を参照

### 3. コスト・リスク診断
選定された技術スタックが、将来的に高額な請求（クラウド破産）に繋がらないか診断します。
